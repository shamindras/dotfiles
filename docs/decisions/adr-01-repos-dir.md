# Repos live in ~/repos

Git repositories live in `~/repos` on both Macs, and the dotfiles clone is `~/repos/dotfiles`. See
[REPOS_DIR](adr-02-repos-dir-var.md) and [no repos in Dropbox](adr-03-no-git-in-dropbox.md).
